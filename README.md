# De UitdagingApp
Responsive PWA voor 5–6 jaar. Start lokaal met `npm install` en `npm run dev`. Productiebuild: `npm run build`.

Inhoud: 120 concrete uitdagingen (20 lezen, 20 taal, 20 rekenen, 20 puzzel, 15 speur, 15 maak, 10 plus). Voortgang staat lokaal in localStorage. Oudergedeelte: houd het slotje rechtsboven 3 seconden vast.
